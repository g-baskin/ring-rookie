## Security Controls Verified

- `backend/app/services/chatgpt_oauth.py:83` generates PKCE and stores the verifier only in Redis.
- `backend/app/services/chatgpt_oauth.py:120` consumes state with Redis `GETDEL`, blocking replay.
- `backend/app/api/chatgpt_oauth.py:73` enforces workspace ownership for every authenticated operation.
- `backend/app/api/chatgpt_oauth.py:108` encrypts access, ID, and refresh tokens before persistence.
- `backend/app/api/chatgpt_oauth.py:61` redirects only to configured frontend URLs and exposes no tokens/codes.
- `backend/app/services/oauth_callback_relay.py:35` accepts only `/auth/callback` and relays to the fixed FastAPI callback.
- `backend/app/api/chatgpt_oauth.py:235` deletes only the caller-owned selected-scope connection.
- `frontend/src/lib/api/settings.ts:70` returns status metadata only; no OAuth bearer token enters browser storage.
