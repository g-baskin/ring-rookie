# Metric Definitions

> **Status:** Freeze before intervention

| Metric | Definition |
|---|---|
| Briefing-use day | Participant inspects the briefing and takes or records a disposition on at least one item |
| Time to first meaningful action | Minutes from observed work-session start to the first real revenue/compliance action, excluding navigation only |
| Context switch | Transition between distinct specialist surfaces or external tools while completing one priority item |
| Actionable disposition rate | `(act + complete + defer) / all surfaced items` |
| Wrong/irrelevant dismissal rate | `(incorrect + irrelevant dismissals) / all surfaced items` |
| Evidence validity | Items with current, inspectable source evidence divided by all surfaced items |
| Continued-use request | Unprompted or final-question request for continued workflow access |

Use participant-day medians, compare each participant with their own baseline, and report profile-level results. Disclose missing sessions, attrition, denominator changes, adverse events, and researcher-prepared items. Never silently impute missing data or alter thresholds after intervention starts.
